## 模型总览（四层）
1. **物理层**：湿球温度（Tetens + 湿球方程二分求解，与 Stull 拟合交叉验证）、
   蒸发冷却 ΔT=min(额定, η·(T_db−T_wb))、风扇体感降温（湿度修正）、
   开放空间逐区点制冷、半开放空间瞬态能量平衡 ODE（30s 步长，时刻表人流脉冲）
2. **舒适/安全层**：体感温度、WBGT_eff、热应激暴露（person-°C·h）、可接受时段占比
3. **效率层**：DHR = 送达人的缓解度·时·人数 ÷ 电耗（person-°C·h/kWh），
   另有热力学 COP 视角与成本视角交叉验证
4. **有效性层**：硬服务底线（可接受占比 ≥ 0.8）+ 四目标加权效用 + 400 组随机权重鲁棒性 + Pareto

## 核心结论（V2，气候参数已按 NOAA/FSU 站点标准值校准）
- 公交站：风扇效率最高（干热 96 person-°C·h/kWh），但 41°C 干热下只有大型冷风机
  把体感温度压到热应激线以下 —— "最有效率 ≠ 最安全"，引出有效性层。
- 车站：恒温滞后控制策略（P3）节能 43-50%（95.8/85.3 vs 169.5 kWh/day）、服务达标 ≈100%，
  有效性第一（干气候 400/400、湿气候 358/400 组随机权重下第一）；
  蒙特卡洛 400 组 plant-uncertainty 抽样下 P3 可行性 98.8-100%。
- 控制设定点经 72 组网格寻优 + 稳健优选：激进设定点名义再省 15-41% 能耗，
  但 P_feasible 仅 0.52-0.85；名义规则 (30/27.5°C, N>70) 被证实为鲁棒最优。
- 尺度检验：同一套方程缩放到 4 个场地 × 4 种气候无需重新标定；
  新增技术选型适用域地图（含"无设备可救"的极端湿热区）。
- 模型验证：能量平衡解析解误差 0.000；欧拉步长 ±1.3%；碳排放核算 -4.3~5.3 tCO2/季。
